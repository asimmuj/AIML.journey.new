# Day 18 - Recursion Fundamentals

## Overview
Today I learned the fundamentals of recursion in Python. Recursion is a technique in which a function calls itself to solve a smaller version of a problem.

## Topics Covered
- Introduction to recursion
- Base case and recursive case
- Understanding recursive function calls
- Call stack and stack unwinding
- Recursion vs loops
- Tracing recursive functions
- Common recursion mistakes

## Programs Practiced
1. Countdown using recursion
2. Factorial calculation
3. Sum of numbers using recursion
4. Printing numbers from 1 to N
5. Power calculation using recursion

## Mini Project: Recursive Number Analyzer

I built a Python program that uses recursion to analyze a positive integer.

### Features
- Counts the number of digits
- Calculates the sum of digits
- Reverses the number

### Example Output
```text
Enter a positive integer: 12345

Number of digits: 5
Sum of digits: 15
Reverse: 54321
```

## Key Learnings
- A base case stops recursive calls.
- A recursive case reduces the problem into a smaller problem.
- Each recursive call uses the call stack.
- Function calls return in reverse order after reaching the base case.
- Incorrect base cases can produce wrong results.
- Recursion is useful for problems involving trees, divide and conquer, and backtracking.
