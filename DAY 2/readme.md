## 🧩 Mini Project — Student Marks Analyzer

The program analyzes student marks and produces:

* Total number of students
* Number of passed students
* Number of failed students
* Highest mark
* Lowest mark
* Average mark

### Example Input

```python
marks = [35, 78, 91, 42, 67, 29, 88]
```

### Example Output

```text
Total students: 7
Passed students: 5
Failed students: 2
Highest mark: 91
Lowest mark: 29
Average mark: 61.43
```

## 🧠 What I Practiced

Instead of relying on built-in functions such as:

```python
max()
min()
sum()
len()
```

I practiced implementing the logic using loops and variables.

For example, the highest mark was found by maintaining a current highest value and comparing every mark against it.

This helped me understand the underlying algorithm rather than simply using a built-in function.
