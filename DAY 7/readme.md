## Mini Project — Student Analyzer 2.0

A Python program that analyzes student marks stored inside a dictionary.

### Features

* Stores multiple students and their marks
* Calculates each student's average
* Determines pass/fail status
* Uses functions for reusable logic
* Uses loops to process students and marks
* Uses conditions for decision making

### Concepts Used

```text
Dictionary
    ↓
Lists
    ↓
Loops
    ↓
Functions
    ↓
Conditions
    ↓
Problem Solving
```
