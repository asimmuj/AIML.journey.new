# 🚀 180-Day AI/ML Internship Roadmap

> A 180-day, project-focused journey to build the skills required to become a competitive AI/ML internship candidate.

## 🎯 Goal

I am a BTech CSE student building my AI/ML skills through a structured 180-day roadmap.

The goal is to develop strong foundations in programming, mathematics, machine learning, deep learning, and AI engineering while building real projects and documenting the entire learning process.

This repository contains my progress, exercises, projects, notes, experiments, and implementations throughout the journey.

> **Learn → Understand → Implement → Build → Explain → Review → Improve**

---

## 🧠 Learning Philosophy

I don't want to blindly copy AI-generated code or follow tutorials without understanding them.

For every major concept, I aim to:

1. Learn the concept
2. Understand how and why it works
3. Implement it myself
4. Build something with it
5. Explain what I built
6. Review my mistakes
7. Improve the implementation

AI tools may be used as a **tutor, debugger, reviewer, and mentor**, but not as a replacement for my own thinking.
